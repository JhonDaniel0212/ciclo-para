# Ejercicio de control de ventas

Una tienda de tecnologia desea llevar uun control de ventas de sus
productos. El día de hoy lanzo una promoción en que sus tres
productos principales serán los unicos que estarán disponibles
Quiere saber cual producto es el mas vendido (entre esos tres) solo 
registrando las primeras 20 compras.

Desarrollar un algoritmo que permita dar solución a la situación planteada

Listado de productos:
- Xioami 18 Fold
- Iphone Duo
- Samsung Galaxy Fold 8
